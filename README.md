# Zenia A. Drilon — Virtual Assistant

A responsive personal portfolio website for a Virtual Assistant, Administrative Support, and Operations professional, built with plain HTML, CSS, and a small amount of JavaScript.

**Live site:** https://zenia-drilon.vercel.app/

## About

Zenia is a Virtual Assistant and Administrative Support professional with 3+ years of experience supporting business operations, data management, customer service, reporting, and team coordination.

This website presents her services, tools, work experience, sample projects, and working style in one place, so clients and employers can quickly see what she offers and how to get in touch.

## Sections

- **Hero**: short introduction, role, and call to action
- **Core Services**: virtual and administrative support, data and operations support, social media and content, and AI-assisted workflows
- **Tools & Platforms**: Microsoft 365, Google Workspace, Oracle, SAP, Meta Business Suite, GoHighLevel, Canva, Photoshop, ChatGPT, and Claude
- **Work Experience**: professional work history
- **Sample Projects**: content creation, AI-assisted video production, administrative and operations support, and data management
- **Working Style**: the Organize, Prioritize, Execute, Review process
- **Contact**: email, LinkedIn, and areas of availability

## Built With

- HTML5
- CSS3 (Flexbox, CSS Grid, CSS variables, media queries)
- Vanilla JavaScript (mobile navigation toggle)
- Google Fonts

No frameworks or build tools are required.

## Features

- Fully responsive layout (desktop, tablet, and mobile)
- Collapsible mobile navigation
- Smooth scrolling between sections
- Lightweight: no dependencies and no build step
